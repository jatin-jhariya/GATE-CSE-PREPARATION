# PERCENTAGE — GATE REVISION

## 1. BASIC

`x% = x/100`

`x% of y = (x/100) × y`

`A is x% of B`
→ `A/B = x/100`

---

## 2. PERCENTAGE CHANGE

`% Change = (Change / Original) × 100`

Increase:

`New = Old(1 + x/100)`

Decrease:

`New = Old(1 − x/100)`

⚠️ **Denominator = ORIGINAL value**

---

## 3. SUCCESSIVE CHANGE

Two changes `a%` and `b%`:

`Net % = a + b + ab/100`

Use signs:

* Increase → `+`
* Decrease → `−`

Example:

`+20%, −10%`

`= 20 − 10 − 2 = 8% increase`

---

## 4. SAME % INCREASE & DECREASE 

Increase by `x%`, then decrease by `x%`:

`Net loss = x²/100 %`

Example:

`+20%, −20%`

→ `4% loss`

---

## 5. REVERSE PERCENTAGE 

If A is `x%` more than B:

`A = B(1+x/100)`

Then B is less than A by:

`x/(100+x) × 100 %`

If A is `x%` less than B:

B is more than A by:

`x/(100−x) × 100 %`

---

## 6. RATIO ↔ PERCENTAGE

If:

`A : B = a : b`

Then A as % of B:

`(a/b) × 100`

If A is `x%` more than B:

`A : B = (100+x) : 100`

If A is `x%` less than B:

`A : B = (100−x) : 100`

---

## 7. POPULATION / PRICE / SALARY

Repeated percentage changes → **successive change formula**

`Final = Initial × (1 ± p/100)^n`

For same percentage increase `p%` for `n` periods.

---

## 8. EXPENDITURE–PRICE–CONSUMPTION

`Expenditure = Price × Quantity`

If expenditure is constant:

`P₁Q₁ = P₂Q₂`

If price increases by `x%`, required decrease in quantity:

`x/(100+x) × 100 %`

If price decreases by `x%`, possible increase in quantity:

`x/(100−x) × 100 %`

---

## 9. MARKS / EXAM QUESTIONS

`Percentage = (Obtained / Total) × 100`

If marks increase from `A → B`:

`% increase = (B−A)/A ×100`

⚠️ Percentage change is always with respect to **old marks**.

---

## 10. FRACTION ↔ PERCENTAGE

Common values:

`1/2 = 50%`

`1/3 = 33⅓%`

`1/4 = 25%`

`1/5 = 20%`

`1/8 = 12.5%`

`1/10 = 10%`

`1/20 = 5%`

`1/25 = 4%`

`1/40 = 2.5%`

`1/50 = 2%`

---

# GATE QUICK TRICKS

`x% of y = y% of x`

`% change → Change / Original ×100`

`Successive changes → a+b+ab/100`

`+x%, −x% → x²/100 loss`

`A x% more than B → B is x/(100+x)% less`

`A x% less than B → B is x/(100−x)% more`

`Constant expenditure → P×Q = constant`

`Increase → multiply by (100+x)/100`

`Decrease → multiply by (100−x)/100`
